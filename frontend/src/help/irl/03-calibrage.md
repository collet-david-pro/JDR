# Calibrer l'échelle

L'échelle est la taille réelle d'une case sur l'écran.

- **Diagonale en pouces** : indiquez la diagonale de l'écran (5 à 300 pouces). Rapide, précis à quelques pour cent.
- **Règle à l'écran** : menu de l'écran, **Calibrage**, onglet **Règle**. Posez une règle contre l'écran, ajustez le trait à une longueur connue, **Enregistrer**. C'est plus précis, et ce réglage **prime sur la diagonale**.
- **Millimètres par case** : 25 par défaut, réglable de 5 à 100.

Quand l'échelle est connue, **le zoom du MJ est ignoré** : seul le centre de la caméra est suivi. Si l'échelle est impossible à atteindre, le menu de l'écran le signale.
