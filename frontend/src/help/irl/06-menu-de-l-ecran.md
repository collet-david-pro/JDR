# Le menu discret de l'écran

Touche **M**, ou **appui long de 2 secondes dans un coin** de l'écran. Le menu propose :

- **Calibrage** ;
- **Rotation** et **Miroir** ;
- l'état de l'écran toujours allumé ;
- **Quitter le plein écran** ;
- **Quitter (désappairer)**, avec confirmation ;
- **Fermer**.
