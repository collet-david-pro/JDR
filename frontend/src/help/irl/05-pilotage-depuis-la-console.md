# Piloter un écran depuis la console

Dans le panneau **Écrans**, pour chaque écran :

- **Suivre la caméra du MJ** : l'écran centre la vue sur la vôtre.
- **Verrouiller ici** : fixe la vue actuelle (centre, zoom, étage) ; **Déverrouiller** la libère.
- **Afficher les tokens** : désactivez-le pour une carte « décor » sans pions, quand on pose les figurines.
- **Nom, diagonale, millimètres par case, rotation, miroir**.
- **Révoquer** : l'appareil revient aussitôt au formulaire d'appairage.

Les **textes à lire** envoyés depuis le panneau Notes s'affichent en grand sur les écrans, et l'écran de pause s'y affiche aussi.
