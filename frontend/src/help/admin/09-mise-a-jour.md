# Mettre à jour le site

Onglet **Mise à jour**.

- Il affiche la version installée, la version de la base et le **canal** (versions stables, ou préversions).
- **Vérifier les mises à jour** interroge GitHub. Si une version est disponible, **Installer la version X** télécharge l'archive, vérifie sa **signature**, puis lance la mise à jour.
- **Mise à jour automatique** (facultative) : le site installe seul les nouvelles versions signées, à l'occasion d'une visite, hors des séances en cours.
- **Envoyer un zip de mise à jour** : pour installer à la main une archive téléchargée. Le récapitulatif montre les fichiers ajoutés, modifiés, supprimés et les migrations avant de confirmer.
- Pendant la mise à jour, le site est en **maintenance**. Une sauvegarde de la base d'avant la mise à jour est proposée au téléchargement.
- Si une mise à jour est interrompue, **Reprendre** la termine.
