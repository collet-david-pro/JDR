# Vérifier l'intégrité

Onglet **Intégrité** : compare la base et les fichiers (quotas, tailles, références d'images, fichiers orphelins, blocs de map illisibles). **Lancer la vérification** liste les problèmes ; chaque groupe propose une correction (recalculer un quota, supprimer un fichier orphelin…), avec confirmation pour toute suppression.

Le bouton **Installer / réparer le pack de base** réinstalle les images de base absentes de la bibliothèque générale et affiche celles qui ont échoué.
