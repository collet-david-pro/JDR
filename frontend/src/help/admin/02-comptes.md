# Gérer les comptes

Onglet **Comptes**.

- **Créer un compte** : e-mail, pseudo, rôle (utilisateur ou administrateur) et mot de passe initial facultatif. Sans mot de passe, le site donne un **lien** à transmettre à la personne (affiché une seule fois).
- **Modifier** un compte : pseudo, rôle, **quota de stockage** (vide : quota par défaut).
- **Suspendre / Réactiver** : une suspension ferme les sessions du compte.
- **Lien de réinitialisation** : pour quelqu'un qui a oublié son mot de passe, surtout si le site n'envoie pas d'e-mails.
- **Supprimer** un compte efface ses données.
- Filtre par statut ; colonnes de dernière connexion et de stockage.
