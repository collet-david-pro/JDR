# Sauvegarder et restaurer

Onglet **Sauvegarde**. Les sauvegardes ne sont pas gardées sur le serveur : elles se téléchargent.

- **Sauvegarder la base de données** (fichier compressé) et **sauvegarder les assets** (archive des images).
- **Restaurer** : choisissez le fichier. Avant de continuer, le site vous invite à télécharger une sauvegarde de l'état actuel, puis demande de **taper un mot de confirmation**. La restauration remplace les données actuelles.
- Après une restauration de la base, toutes les sessions sont fermées : reconnectez-vous. Si la base vient d'une version plus ancienne, ouvrez la page de mise à jour.
