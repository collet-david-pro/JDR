# Les invitations

Onglet **Invitations**, utile quand les inscriptions sont « sur invitation ».

- **Nouvelle invitation** : e-mail du destinataire (facultatif : réserve l'invitation à cette adresse), nombre d'utilisations, validité en jours (vide : sans expiration).
- Le **code** (et le lien `/invite/<code>`) est à transmettre à la personne.
- La liste montre les utilisations et l'expiration ; **Supprimer** rend l'invitation inutilisable.
