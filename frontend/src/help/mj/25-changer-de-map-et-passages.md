# Changer de map et emprunter un passage

Panneau **Maps** de la console.

- **Changer de map** : tous les joueurs passent sur la nouvelle map (confirmation demandée). Vous pouvez aussi choisir l'étage.
- Le panneau **Passages** liste les escaliers, portails et portes avec lien de l'étage courant. **Emprunter** ouvre une fenêtre : choisissez les **tokens à déplacer avec le groupe** et, si besoin, la position d'arrivée en cases.
- Un lien « cassé » doit être corrigé dans l'éditeur.
- Dans l'éditeur, l'arrivée d'un lien se saisit en chiffres ou avec **Choisir sur la map** : cliquez le point sur l'aperçu de la map cible (Échap annule).
