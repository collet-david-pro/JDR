# Gérer les joueurs

Onglet **Joueurs** de la partie.

- **Ajouter un joueur** : saisissez son pseudo ou son e-mail. Le compte doit déjà exister sur le site (sinon, [invitez-le](#admin-invitations) ou demandez à l'administrateur).
- **Rôle** : _Joueur_ ou _Co-MJ_. Un co-MJ peut préparer et diriger comme vous.
- **Retirer** un joueur lui enlève l'accès à la partie. Vous pourrez le rajouter plus tard.

Un joueur peut aussi arriver tout seul : le code d'une séance l'ajoute à la partie. Voir [lancer une séance](#mj-lancer-une-seance).
