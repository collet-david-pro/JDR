# Modèles de map

Un **modèle** est une map prête à resservir.

- **Nouvelle map depuis un modèle** : bouton **Depuis un modèle** de l'onglet Maps. Les modèles **livrés** et ceux du site sont dans une section, les vôtres dans une autre. Choisissez-en un, nommez la nouvelle map.
- **Enregistrer comme modèle** : depuis la carte d'une map. Le modèle garde le terrain, les murs, les lumières, les étages et les notes. Il ne garde ni les tokens posés, ni le brouillard, ni les secrets déjà révélés, ni les liens vers d'autres maps.
- **Visibilité** : _Moi seul_ ou _Tout le site_ (visible de tous les MJ).
- Un modèle du site ne peut pas partager des images qui ne sont qu'à vous : remplacez-les d'abord par des images de la bibliothèque générale.
- **Supprimer** un modèle ne change pas les maps déjà créées avec lui.
