# Historique des versions

Le bouton **Historique** de l'éditeur liste les versions de la map. Un instantané **automatique** est créé toutes les 5 minutes d'édition ; vous pouvez en créer un **manuel** avec un libellé (« Avant d'ajouter la crypte »), ou avec **Ctrl+Maj+S**.

**Restaurer** une version ramène la map à cet état. L'état actuel est d'abord sauvegardé dans un instantané « Avant restauration » : vous pouvez toujours revenir en arrière. L'historique annuler / rétablir est remis à zéro. Le site conserve un nombre limité de versions (réglage de l'administrateur).
