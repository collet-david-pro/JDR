# Enregistrement et hors ligne

L'éditeur enregistre tout seul. L'indicateur du haut affiche **Enregistrement…**, **Enregistré**, ou **Hors ligne** avec le nombre de modifications en attente.

- Hors ligne, vos modifications sont gardées dans le navigateur et envoyées dès que la connexion revient.
- Si la map a changé ailleurs, le site résout le conflit ou vous demande de recharger : vos modifications sont conservées.
- Si votre session expire, reconnectez-vous : rien n'est perdu.
- Si le navigateur ne peut pas garder de données locales, un avertissement vous prévient : fermer la page perdrait les modifications non envoyées.
