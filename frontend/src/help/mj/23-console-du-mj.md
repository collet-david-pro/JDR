# La console du MJ

La console montre la map comme la voient les joueurs, avec vos outils. Le bandeau du haut donne le nom et l'état de la séance, le code, **Lancer / Pause / Reprendre / Terminer**, **Les joueurs suivent ma vue**, **Partager ma vue**, **Diffuser ma caméra** et **Écran de pause…**.

Les **panneaux** de côté :

- **Joueurs** : qui est connecté et prêt ; affectation des tokens (glissez un token sur un joueur) ; **Exclure** un joueur.
- **Tokens** : poser un token de la partie (option **Poser masqué**), puis la liste des tokens posés : masquer, révéler, retirer.
- **Révéler** : le brouillard et les objets (voir [brouillard](#mj-brouillard-et-revelations)).
- **Ambiance** : obscurité, teinte, heure, météo.
- **Notes** : afficher un texte aux joueurs, notes de la map, partage.
- **Maps** : changer de map, passages.
- **Écrans** : écrans de projection.

La palette **Ctrl+K** y fonctionne aussi. **Échap** revient à l'outil de sélection.
