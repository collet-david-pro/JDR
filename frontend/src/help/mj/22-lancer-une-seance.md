# Lancer une séance

Onglet **Séances** de la partie.

1. **Nouvelle séance** : nom (un nom daté est proposé) et **map de départ** (modifiable ensuite). Une seule séance peut être ouverte à la fois.
2. Vous arrivez dans la **console** avec un **code de séance**. Donnez-le à vos joueurs ; **Régénérer le code** invalide l'ancien.
3. Dans la salle d'attente, les joueurs arrivent et se disent prêts. Affectez-leur des tokens (panneau **Joueurs**).
4. **Lancer** démarre la séance.

Pendant la séance : **Pause** et **Reprendre**, puis **Terminer** (les joueurs sont déconnectés ; c'est définitif). Une séance ouverte se rouvre depuis la liste des séances ; une séance terminée se consulte seulement.

Les écrans de projection s'ajoutent aussi à la séance : voir la section [Écran IRL](#irl-mise-en-place).
