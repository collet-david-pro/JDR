# Créer des tokens

Un **token** est un pion : personnage, monstre, objet. Onglet **Tokens** de la partie, bouton de création.

- **Nom, image et taille** (en cases) : l'image vient de [votre bibliothèque](#mj-bibliotheque-d-images).
- **Générer une image** : pour un PNJ ou un monstre sans image, le générateur de tokens dessine un pion (forme, couleurs, anneau, emblème ou portrait recadré). L'image est rangée dans votre bibliothèque, comme image de token, et choisie pour ce token.
- **Anneau de couleur** : un cercle coloré autour du pion, pratique pour distinguer des monstres identiques.
- **Vision** : le token voit et dévoile le brouillard. Réglez la portée, et la **vision dans le noir**. Les distances sont en cases.
- **Lumière** : le token porte une lumière (torche, lanterne) avec un rayon de lumière vive et un rayon de lumière faible. Les murs la bloquent.
- **Propriétaire** : le joueur qui recevra ce token en séance. Vous pourrez le changer dans la salle d'attente.
- **Token du joueur** : si le propriétaire a choisi un token de sa collection, il remplace votre image. La case **Imposer mon image** de la fiche rétablit la vôtre, et la décocher rend la main au joueur.

Les tokens se posent ensuite sur les maps, dans l'éditeur ou pendant la séance.

> Le pack de base de la bibliothèque contient déjà une quarantaine de tokens (héros, monstres, PNJ, animaux) prêts à l'emploi.
