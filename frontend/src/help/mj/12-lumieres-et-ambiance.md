# Lumières et ambiance

**Lumière** (L) : cliquez pour poser, glissez pour régler le rayon. Préréglages : torche, lanterne, bougie, feu de camp, lumière magique. Dans les propriétés : rayon de lumière vive et faible, couleur, intensité, **vacillement** (torche, pulsation), **cône** (ouverture et direction). Les murs bloquent la lumière.

Panneau **Ambiance** de l'éditeur (et de la console pendant la séance) :

- **Obscurité** : de 0 à 100 %. Plus c'est sombre, plus les lumières comptent.
- **Teinte** de l'éclairage ambiant.
- **Heure du jour** : cycle jour / nuit.
- **Météo** (aucune, pluie, neige, brume, orage) et intensité : elle est enregistrée avec la map ; les effets visuels viendront plus tard.

Le menu **Vue** permet de prévisualiser : **Vue MJ**, **Comme tous les PJ** ou **Comme** un token précis, avec l'éclairage, le brouillard et les ombres activés ou non.
