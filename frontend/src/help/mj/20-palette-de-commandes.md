# La palette de commandes

**Ctrl+K** (Cmd+K sur Mac) ouvre une barre de recherche d'actions, dans l'éditeur comme dans la console du MJ.

Tapez quelques lettres : la recherche ignore les accents et les majuscules. Elle trouve les outils, les calques, les étages, les panneaux, l'annulation, l'export, la génération… et, dans la console, les actions de séance (changer de map, emprunter un passage, lire une note, révéler un token, ajouter un écran…). Chaque ligne affiche son raccourci quand il existe. **Entrée** lance l'action, **Échap** ferme.
