# Créer un compte

Pour jouer, il faut un compte sur le site. La façon de le créer dépend d'un réglage de l'administrateur.

- **Inscriptions ouvertes** : cliquez sur **Créer un compte** sur la page de connexion.
- **Sur invitation** : le MJ ou l'administrateur vous envoie un lien ou un code d'invitation. Ouvrez le lien (il se termine par `/invite/` suivi du code), ou saisissez le code sur la page d'inscription.
- **Inscriptions fermées** : demandez à l'administrateur de créer le compte pour vous. Il vous donne un lien pour choisir votre mot de passe.

Sur le formulaire, indiquez une adresse e-mail, un pseudo (3 à 40 caractères), puis un mot de passe d'au moins 10 caractères, à confirmer. Évitez les mots de passe trop courants : le site les refuse.

> Une phrase de passe (plusieurs mots) est plus facile à retenir et plus solide qu'un mot compliqué.
