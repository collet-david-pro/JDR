# La salle d'attente

Avant le début, la salle d'attente montre :

- **Joueurs** : qui est connecté et qui est prêt ;
- **Vos tokens** : les personnages affectés à votre compte (le MJ les affecte, parfois au dernier moment) ;
- **Préchargement de la map** : le site télécharge les images (tuiles, tokens, images posées sur la map) pour que le jeu démarre vite. Seul ce que vous avez le droit de voir est téléchargé.

Quand le préchargement est fini, cliquez sur **Je suis prêt**. Le MJ voit combien de joueurs sont prêts. Vous attendez ensuite que le MJ lance la séance.

Le bouton **Quitter la séance** vous ramène à l'accueil.
