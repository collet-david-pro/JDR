# En cas de problème

- **« Hors ligne » ou « Reconnexion… »** : attendez quelques secondes, le site se reconnecte seul. Si cela dure, rechargez la page.
- **Le site affiche « maintenance »** : l'administrateur travaille sur le site. La page se recharge d'elle-même quand tout est revenu.
- **Un bandeau propose de recharger** : une nouvelle version du site est prête. Cliquez sur **Recharger**.
- **Session expirée** : reconnectez-vous ; vous revenez à la page où vous étiez.
- **Code refusé** : vérifiez le code avec le MJ ; il peut l'avoir régénéré.
- **Écran blanc ou image manquante** : rechargez la page. Un navigateur récent est nécessaire (Chrome, Firefox, Safari ou Edge à jour).
