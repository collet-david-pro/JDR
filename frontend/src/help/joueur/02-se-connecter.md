# Se connecter et se déconnecter

Sur la page de connexion, saisissez votre **e-mail ou votre pseudo** et votre mot de passe, puis **Se connecter**.

- **Se souvenir de moi** garde votre connexion sur cet appareil. Évitez-le sur un ordinateur partagé.
- **Mot de passe oublié ?** Si le site sait envoyer des e-mails, saisissez votre adresse : vous recevez un lien pour choisir un nouveau mot de passe. Sinon, demandez à l'administrateur : il peut vous donner un lien de réinitialisation.
- Après trop d'essais ratés, le site vous demande d'attendre un peu avant de réessayer.

Le bouton **Déconnexion** se trouve en haut à droite. Pour fermer toutes vos sessions sur d'autres appareils, voir [le profil](#joueur-profil-et-apparence).
