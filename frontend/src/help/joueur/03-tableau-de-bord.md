# Le tableau de bord

C'est la page d'accueil après la connexion. Elle montre :

- **Mes parties (MJ)** : les parties que vous dirigez, avec un bouton **Nouvelle partie**. Voir [créer une partie](#mj-creer-une-partie).
- **Parties où je joue** : les parties dont un MJ vous a ajouté, ou que vous avez rejointes avec un code.
- **Rejoindre une séance** : un champ pour saisir le code que le MJ vous donne. Voir [rejoindre une séance](#joueur-rejoindre-une-seance).
- **Stockage** : l'espace utilisé par vos images, avec un lien vers [la bibliothèque](#mj-bibliotheque-d-images).

La barre du haut donne accès à la bibliothèque, au profil, au thème (clair, sombre, style) et à cette aide.
