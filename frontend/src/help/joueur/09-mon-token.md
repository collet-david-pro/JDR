# Créer mon token

Vous fabriquez votre propre pion, sans logiciel de dessin. Section **Mes tokens** du **Profil**.

- **Nouveau token** : choisissez une **forme** (disque, hexagone, écu, carré, losange), la **couleur de fond**, la **couleur et l'épaisseur de l'anneau**, puis un **emblème** (classes, créatures, symboles) avec sa couleur, ou un **portrait** de votre appareil.
- **Portrait** : faites-le glisser pour le cadrer, zoomez à la molette, avec le curseur ou en pinçant à deux doigts. Au clavier : flèches pour déplacer, **+** et **-** pour zoomer.
- **Collection** : jusqu'à 100 tokens par compte. Vous pouvez les **modifier** (le cadrage est conservé), **renommer**, **dupliquer** et **supprimer**.

## Utiliser un token dans une partie

- En **rejoignant une séance**, choisissez un token dans la liste ; il sera le vôtre dans cette partie.
- Ensuite, depuis la **page de la partie**, section **Mon token**, vous pouvez en changer, mais **seulement hors séance**.
- Votre token remplace l'image mise par le MJ sur le pion qui vous est attribué. Si aucun pion n'est à votre nom, la partie en crée un que le MJ pourra poser sur la map.
- Si vous supprimez un token utilisé dans une partie, une confirmation est demandée et la partie retombe sur l'image du MJ.

> Le MJ peut à tout moment **imposer sa propre image** sur votre pion, puis revenir à la vôtre : rien n'est perdu.
