# Jouer pendant la séance

Vous voyez la map de la séance, vos tokens et ce qu'ils voient.

- **Déplacer un token** : glissez-le vers une case. Si le MJ a interdit les déplacements aux joueurs, seul lui peut le faire.
- **Les murs bloquent** : un token ne traverse ni mur ni porte fermée. Le message « Bloqué par un mur » apparaît.
- **Brouillard** : vous ne voyez que ce que vos tokens voient, plus les zones déjà explorées. Le reste reste noir.
- **Zoom et déplacement** : molette ou pincement pour zoomer, glisser le fond de la map pour la déplacer.
- **Suivre le MJ** : cochez la case pour que votre vue suive celle du MJ. Décochez pour regarder où vous voulez.
- **Centrer sur mon token** : ramène la vue sur votre personnage.

En haut, un voyant indique la connexion : **Connecté**, **Reconnexion…** ou **Hors ligne**. Le site choisit seul le meilleur moyen de rester à jour (temps réel, long polling ou interrogation régulière) ; vous n'avez rien à régler.
