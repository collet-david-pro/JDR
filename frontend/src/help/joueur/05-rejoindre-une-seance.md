# Rejoindre une séance

1. Demandez au MJ le **code de séance** (il l'affiche dans sa console).
2. Saisissez-le dans **Rejoindre une séance** sur le tableau de bord, ou ouvrez le lien `/join/` suivi du code.
3. Vous arrivez dans la [salle d'attente](#joueur-salle-d-attente).

Si vous ne faisiez pas encore partie de la partie, le code vous y ajoute comme joueur. Si le MJ vous a exclu de la séance, le code est refusé. Une séance terminée ne peut plus être rejointe.
